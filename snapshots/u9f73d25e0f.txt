An Error Occurred While Using YourTexasBenefits.com
Something went wrong on a page while you were using YourTexasBenefits.com. Please email us at YourTexasBenefits@hhs.texas.gov so we can review it.
In the subject line, include “Your Texas Benefits” and the event ID (listed at the bottom of the error message with the host and time stamp). In the email, include:
Link to the page you’re having trouble with.
Brief description of the issue along with the following details:
Event ID
Host
Time stamp
If you need help with your benefits or the website, call 2-1-1 or 877-541-7905 . Select your language and then Option 2.
Ha ocurrido un error mientras usted usaba YourTexasBenefits.com
Algo falló en una página web mientras usted usaba YourTexasBenefits.com. Envíenos un correo electrónico a YourTexasBenefits@hhs.texas.gov para que podamos investigar el error.
En la línea del asunto, escriba “Your Texas Benefits” y el número de identificación del suceso (que aparece en la parte inferior del mensaje de error junto con el nombre del servidor y el registro de la hora). En su correo electrónico, incluya:
el enlace a la página con la que ha tenido problemas.
una breve descripción del problema junto con los siguientes detalles:
el número de identificación del suceso
el nombre del servidor
el registro de la hora
Si necesita ayuda con sus beneficios o con el sitio web, llame al 2-1-1 o al 877-541-7905 . Seleccione su idioma y luego la opción 2.
