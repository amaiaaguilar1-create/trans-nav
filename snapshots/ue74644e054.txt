Change of Name
Note: All forms are Adobe Acrobat PDF documents unless otherwise indicated.
&emsp;Adults
An adult's name may be returned to a previous name as part of a divorce or dissolution proceeding, otherwise it must be done in a separate Change of Name Case.
&rtrif; Adult Change of Name Forms:
&rtrif; CIV-698 Cover Sheet
&rtrif; CIV-699 Instructions for Adult Change of Name
&rtrif; CIV-700 Petition for Change of Name
&rtrif; VS-405 / Application or Report of
Change of Name
&emsp;Children
A child's name can be changed as part of an adoption proceeding, otherwise it must be done in a separate Change of Name Case.
&rtrif; Child's Change of Name Forms:
&rtrif; CIV-692 Cover Sheet
&rtrif; CIV-693 Instructions for Child's Change of Name
&rtrif; CIV-694 Petition to Change Child's Name
&rtrif; CIV-695 Parental Consent from Non-Petitioning Parent
&rtrif; VS-405 / Application for Report of
Change of Name
If you object to the child's name being changed, you can file the form:
CIV-696 Objection to Change of Name
