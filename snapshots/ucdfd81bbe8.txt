Name change interview
Read before you start
When you click the link below, it will take you to the A2J website where you will be asked a series of questions. At the end of the questions, you will be able to download and print off the court forms you will need to file a Petition for Name Change in Georgia.
You will still need to file these forms with the court. This program does not e-file the forms for you.
The A2J program does not give legal advice. Only a lawyer can provide legal advice.
Read more about name changes and gender marker change laws in Georgia to decide whether you are ready to file.
