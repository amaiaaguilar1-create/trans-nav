DMV verifies with the Social Security Administration
DMV verifies a customer’s social security number with Social Security Administration, so customers wanting to change their name on their credential must first change their name with SSA.
For
REAL ID we need to verify both legal name and social security number with the SSA. The name on the credential must match that on file with the SSA.
For standard credentials, we can complete the social security online verification in another name if we receive
proof of that name . The name on the credential can be different from the SSA's information.
